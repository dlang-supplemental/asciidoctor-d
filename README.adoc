== Purpose

Fast, memory-safe AsciiDoc processing in D for CLI conversion and (later) editor
source-of-truth tooling (LSP tokens, diagnostics, preview).

Primary goals:

* Performance (LDC/GDC)
* Correctness vs Asciidoctor behavior
* Clear errors and a maintainable codebase

== Usage

[source,bash]
----
dub build --config=application
./asciidoctor-d input.adoc
./asciidoctor-d -o out.html input.adoc
./asciidoctor-d -b manpage -o prog.1 prog.adoc
./asciidoctor-d -b pdf -o out.pdf input.adoc
----

Library API:

[source,d]
----
import asciidoctor;
auto html = convert(source, "html5", baseDir);
auto man = convert(source, "manpage", baseDir);
auto pdf = convert(source, "pdf", baseDir);
----
