Native D implementation of Asciidoctor.

Repository: https://github.com/dlang-supplemental/asciidoctor-d

== Purpose

This project aims to provide a fast, memory-safe, and correct implementation of AsciiDoc processing in the D programming language.

Primary goals:
- Performance (native compilation via LDC/GDC)
- Correctness (parsing and AST fidelity)
- Better error messages than current Ruby implementation
- Clean, maintainable codebase without "piping data to a defective core"

== Usage

[source,bash]
----
dub build
./asciidoctor-d input.adoc
----
