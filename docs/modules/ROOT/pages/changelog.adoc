== 2026-11-10

HTML links and images stay on an allowlist.

=== Safe href and src
* `ConvertOptions.urlFilter` rewrites a URL before it is written into `href` or `src`.
* Emitted URLs are limited to `http`, `https`, `mailto`, a fragment, or a relative path. Any other scheme, a protocol-relative URL, or a URL that contains an ASCII space or control is left out. The link or image label stays as text.
