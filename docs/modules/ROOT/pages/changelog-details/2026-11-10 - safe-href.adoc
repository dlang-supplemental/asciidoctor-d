== Safe href and src

`ConvertOptions.urlFilter` receives each URL before the HTML5 converter writes `href` or `src`. The converter then keeps only `http`, `https`, `mailto`, a fragment, or a relative path.

A `javascript:` or `data:` link is not emitted. The visible label stays as text. The same check applies to images, cross references, and the table of contents.
